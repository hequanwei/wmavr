# wmavr

看显卡、头显和家里的 Wi-Fi，估一个能用的 PCVR 串流编码和码率。

- [串流诊断](https://wmavr.com/rig/)：看先卡在显卡、头显还是网络
- [硬件](https://wmavr.com/hardware/)：快速判断，以及头显和显卡代际能不能处理 AV1
- [工具目录](https://wmavr.com/directory/)：串流、WebXR、空间视频、建筑可视化和三维资产
- [能力表](https://wmavr.com/table/)：诊断用的数字和出处

估算按 90Hz 和头显默认分辨率。码率来自 Virtual Desktop 的公开上限，网络按经验值。不测当前网速，也不预测某一款游戏的帧率。

网站：https://wmavr.com/
